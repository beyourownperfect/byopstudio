## Source
Cloned from `beyourownperfect/blum` (main branch). Existing Emergent project.

## Tech Stack
- Backend: FastAPI + Motor (MongoDB)
- Frontend: React (CRA + craco) + Tailwind + Radix UI
- Single-user GATE CSE study tracking OS

## Modules
- **Pulse** — daily mission, momentum, weak topics, GATE readiness, subject completion
- **Solve / Practice** — SRS-based question practice (MCQ/MSQ/NAT)
- **Log** — study log entries
- **Timeline** — daily activities + scheduled revisions
- **Bookmarks / Mistakes / Repository** — additional views
